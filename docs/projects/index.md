# 프로젝트별 규칙

[전체 목차](../index.md)

특정 프로젝트·엔진·플랫폼의 설계, 구성·빌드와 공통 규칙의 예외를 다룬다. 프로젝트의 규모와 지원 환경에 따라 달라지는 선택을 이곳에 모으고, 공통 규칙은 관련 문서를 링크로 참조한다.

상태: 세부 규칙 미작성. 아래 항목과 DX12·Windows·COM 등은 정리 후보이며 아직 별도 규칙을 채택하지 않았다.

## 다룰 내용

- **설계**: 책임과 인터페이스 경계, 모듈·계층의 의존성, 데이터 흐름, 디자인 패턴의 선택 이유와 적용 조건
- **프로젝트 구성·빌드**: 소스·헤더·테스트·에셋·생성물 배치, 실행 파일·라이브러리·테스트 타깃, 언어 표준·컴파일러·외부 의존성, 빌드 옵션과 개발 도구, 빌드·실행 방법
- **공통 규칙의 예외와 프로젝트 제약**: 적용할 공통 기준, 달라지는 내용과 이유, 엔진·플랫폼 API와 자원 수명에 관한 제약

프로젝트 문서는 목적·대상 환경·적용 범위를 먼저 밝히고 필요한 내용만 작성한다. 위 항목마다 별도 문서나 목차를 만들지는 않는다. 공통 규칙의 상세 정의는 복제하지 않는다.

관련 문서: 언어 사용과 RAII·스마트 포인터 사용·전달은 [코딩](../coding/index.md)과 [C++ 소유권·수명](../coding/cpp/ownership.md), 테스트 대상과 통과 기준은 [테스트·품질](../quality/index.md)을 참고한다.

프로젝트별 문서가 작성되면 이 목차에 연결한다.

## 변경 기록

- 2026-09-14: 사용자 선택에 따라 설계와 프로젝트 구성·빌드의 미작성 목차를 이 문서로 통합했다. 프로젝트마다 달라지는 선택을 모아 최상위 분류를 줄였으며 세부 규칙은 미결정 상태로 유지했다.
