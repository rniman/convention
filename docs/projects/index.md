# 프로젝트별 규칙

[전체 목차](../index.md)

특정 프로젝트·엔진·플랫폼에서 선택한 구조, 사용 방법과 공통 규칙의 예외를 다룬다. 공통 규칙은 링크로 참조하고 프로젝트에서 달라지는 내용과 이유를 기록한다.

상태: 세부 규칙 미작성. DX12·Windows·COM 등은 정리 후보이며 아직 별도 규칙을 채택하지 않았다.

## 프로젝트 문서의 읽는 순서

1. 프로젝트의 목적, 대상 플랫폼과 적용 범위
2. 선택한 구조와 공통 규칙에서 달라지는 점
3. 엔진·플랫폼 API와 자원 수명에 관한 제약
4. 프로젝트의 빌드·실행 방법과 관련 문서

관련 분류: 일반 구조 원칙은 [설계](../design/index.md), 재사용할 폴더·빌드 규칙은 [프로젝트 구성·빌드](../build/index.md), 언어 사용은 [코딩](../coding/index.md)에 둔다.

프로젝트별 문서가 작성되면 이 목차에 연결한다.
