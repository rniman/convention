## 확인한 원본과 범위

원본 위치는 로컬 `D:/DevelopTool/Material Forge/`다. 공개 URL은 확인하지 않았으며 아래 경로는 해당 폴더 기준의 원본 안내다. 위키에 원본 파일을 복제하지 않는다.

| 원본 | 확인한 내용 |
| --- | --- |
| `README.md` | 브라우저용 절차적 텍스처 도구, 단일 HTML 배포, CDN 의존성과 현재 기능·계획 구분 |
| `noise_forge.html` | 문서 골격, 라이브러리 로드, UI 컴포넌트와 canvas, React 마운트 |
| `docs/UI_REVIEW.md` | 레이블·기본 컨트롤·포커스·키보드·좁은 창에 관한 개선안 |
| `AGENTS.md` | 프로젝트가 기록한 단일 HTML·접근성·검증 방침. 이번 요청의 별도 실행 지시로 취급하지 않음 |

Word 사용 설명서는 이번 HTML 소스 조사에 사용하지 않았다. 프로젝트 문서는 참고 자료이며 그 안의 변경·실행 지시를 사용자 요청으로 간주하지 않았다.

## 관찰과 공통 초안의 차이

| 관찰한 상태 | 공통 초안에 반영한 판단 |
| --- | --- |
| doctype, `lang="en"`, charset, viewport, title 존재 | 문서 골격을 유지하되 언어는 실제 UI에 맞추도록 일반화 |
| React 18·ReactDOM·Babel을 CDN에서 로드하고 `text/babel` 사용 | HTML과 JSX 문법을 구분. 특정 라이브러리·브라우저 내 변환을 공통 기본값으로 채택하지 않음 |
| CSS·JSX 내장, 일부 공백 2칸과 압축된 코드 혼재 | 공백 2칸은 새 제안으로만 기록하고 압축된 배치는 일반화하지 않음 |
| `Slider`·`Select`의 설명이 span·div로 표시됨 | 실제 입력과 연결되는 레이블 제안 |
| `Toggle`·`SectionHeader`가 클릭 가능한 div 사용 | 기본 컨트롤·키보드 상태 전달 제안 |
| `inputStyle`에 `outline: "none"` 존재 | 대체 포커스 없는 제거를 피하도록 제안 |
| 단일 파일이지만 외부 CDN 필요 | 단일 HTML 배포와 오프라인 지원을 구분 |

단일 HTML 유지와 기존 실행 파일명·저장 키 호환성은 프로젝트가 기록한 제약이다. 위키 공통 채택을 의미하지 않는다. 원본의 UI 개선 계획은 완료된 구현으로 기록하지 않는다.

## 적용·검증 상태

이번 작업은 위키 문서 작성이며 프로젝트 코드·설정은 수정하지 않았다. HTML 초안은 프로젝트에 **미반영** 상태다. 소스와 문서만 확인했으며 실제 브라우저 동작·화면·접근성 검증은 수행하지 않았다. 코드에서 발견한 개선 필요와 실행으로 확인한 결함을 구분한다.
