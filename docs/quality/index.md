# 테스트·품질

[전체 목차](../index.md)

코드와 시스템의 동작을 검증하고 회귀를 예방하는 기준을 다룬다.

상태: 세부 규칙 미작성. 아래 항목은 후속 정리 대상이다.

## 정리할 순서

1. 단위·통합 테스트의 범위와 대상
2. 테스트 케이스·데이터 작성과 회귀 검증
3. 정적 분석 결과의 처리 기준
4. 성능 측정 방법과 결과 판단 기준

테스트 실행 타깃과 도구 연결은 [프로젝트 구성·빌드](../build/index.md), 협업 중 리뷰 절차는 [Git·협업](../git/index.md)에 둔다. 세부 문서는 작성 후 이 목차에 추가한다.
