# 테스트·품질

[전체 목차](../index.md)

코드와 시스템의 동작을 검증하고 회귀를 예방하는 기준을 다룬다.

상태: 초안 작성, 채택 미정.

## 작성한 초안

- [변경 검증과 결과 기록](verification.md): 변경 범위에 맞는 검증, 빌드·실행·화면 구분과 성능 측정 조건.

## 정리할 순서

1. 단위·통합 테스트의 범위와 대상
2. 테스트 케이스·데이터 작성과 회귀 검증
3. 정적 분석 결과의 처리 기준
4. 성능 측정 방법과 결과 판단 기준

테스트 실행 타깃과 도구 연결은 [프로젝트별 규칙](../projects/index.md), 협업 중 리뷰 절차는 [Git·협업](../git/index.md)에 둔다. 구체적인 테스트 도구·통과 기준과 정적 분석 정책은 후속 정리 대상이다.
