각 규칙의 상세 정의는 해당 문서에서 관리한다. 다른 문서의 예제는 설명에 필요한 범위에서 같은 규칙을 적용한다.

목차는 포맷·명명·주석으로 코드의 표현을 정한 뒤, 자료형 선택·초기화·const·변환으로 값과 타입을 다루고, 클래스·구조체에서 사용자 정의 타입을 설계한 다음 헤더·함수·attribute·소유권으로 파일 구성과 API·자원 관리를 읽는 순서다. 자료형 선택·타입 변환·attribute와 클래스 문서의 미결정 정책은 초안이므로 채택 규칙과 구분해 검토한다. 특정 프로젝트의 클래스와 모듈의 책임·의존성 구조는 [프로젝트별 규칙](../../projects/index.md)에서 다룬다.
