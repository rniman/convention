# 코딩

[전체 목차](../index.md)

언어별 코드 작성과 안전한 기능 사용을 다룬다. 명명·포맷뿐 아니라 초기화, 함수 인터페이스, 자원 관리처럼 해당 언어에서 직접 구현하는 규칙을 포함한다.

## 하위 문서

- [C++](cpp/index.md): 프로젝트 구조·클래스·구조체를 포함한 채택 문서 11개와 자료형 선택·타입 변환·attribute 초안. 네임스페이스 명명도 채택 범위에 포함한다. 채택 문서 안의 초안·미결정 정책은 제외하며 목차에 안내된 순서로 읽는다.
- [HLSL 셰이더 규칙](hlsl.md): 명명·단계별 파일·진입점·공유 include·산출물 구분 초안.
- [좌표축과 행렬 규약](coordinates-and-matrices.md): 엔진·API에 따른 좌표축 선택과 DirectXMath↔HLSL 행렬 전달·검증·성능 예외의 채택 기준.
- [HTML 기본 컨벤션](html.md): 문서 골격·포맷·입력·접근성·JSX 차이 초안.

C 규칙은 후속 정리 대상이다. C++ 규칙을 C의 기본 규칙으로 적용하지 않는다.

공통 C++ 코드 배치·공개 헤더 분리·Visual Studio의 프로젝트·필터 구성 기준은 [프로젝트 구조와 파일 배치](cpp/project-structure.md)에서 다룬다. 특정 프로젝트의 구체적인 책임·의존성 구조, 실제 디렉터리·빌드 환경과 공통 기준의 예외·적용 결과는 [프로젝트별 규칙](../projects/index.md)에서 다룬다.

## 변경 기록

- 2026-10-16: 프로젝트 구조·파일 배치 문서의 이동·재구성과 공통 규칙 채택, 채택 문서 11개를 반영했다. 구체적인 구조·API·분리 대상은 프로젝트별 결정으로 안내하며 네임스페이스도 공통 규칙으로 채택하고 실제 루트 이름·모듈 구분은 프로젝트별로 결정한다.
