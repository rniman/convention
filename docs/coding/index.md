# 코딩

[전체 목차](../index.md)

언어별 코드 작성과 안전한 기능 사용을 다룬다. 명명·포맷뿐 아니라 초기화, 함수 인터페이스, 자원 관리처럼 해당 언어에서 직접 구현하는 규칙을 포함한다.

## 하위 문서

- [C++](cpp/index.md): 현재 채택된 8개 규칙. 목차에 안내된 순서로 읽는다.

C 규칙은 후속 정리 대상이다. C++ 규칙을 C의 기본 규칙으로 적용하지 않는다.

관련 분류: [설계](../design/index.md)는 책임과 의존성 구조를, [프로젝트 구성·빌드](../build/index.md)는 디렉터리와 빌드 환경을 다룬다.
