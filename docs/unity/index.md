# Unity

[전체 목차](../index.md)

상태: 초안 · 적용 범위: 여러 Unity 프로젝트에서 검토할 공통 작업 규칙

Unity 오브젝트·에셋 명명과 프로젝트 내부 정리를 다룬다. 특정 Unity 버전을 공통 기준으로 고정하지 않는다. 자료의 확인 버전과 실제 프로젝트의 사용 버전은 구분한다.

## 하위 문서

- [오브젝트·에셋 이름과 폴더 구조](organization.md): PascalCase와 구분자, 반복 이름·번호, Prefab·Scene 이름, 기본 폴더와 이동 시 참조 보존.

모든 항목은 채택 전 제안이다. C# 코드 스타일은 후속 범위다. 특정 프로젝트의 구조·예외·시험 적용 결과는 [프로젝트별 규칙](../projects/index.md)에 기록하고 공통 규칙 전문은 이 분류에만 둔다.
